# Deprecated RFCs and ADRs

This directory is a historical archive. SPEC-0001 retires RFCs and ADRs; new
decisions are recorded as specs in [`docs/spec/`](../spec/).

These documents are kept for traceability. They are not normative. Do not add
new files here. If a historical decision still applies, restate it in an active
spec or in the canonical rule document that owns it.
[SPEC-0002](../spec/0002-restate-active-decisions.md) owns the active-decision
restatement.

The archive is frozen when SPEC-0001 is accepted. The files were moved here on
2026-11-23; RFC-0004, ADR-0010, and ADR-0011 were added as they stood at that
date.
